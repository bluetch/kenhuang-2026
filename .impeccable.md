# Design Context — KEN.EXE Portfolio

## Identity
Amateur indie game developer, product designer, and frontend developer.
Ken Huang — Level 15, Taipei, Taiwan.

## Design Direction
**Indie Pixel Art / Dark Game Dev** aesthetic.
Inspired by: itch.io, Game Jam pages, retro indie game studios, CRT monitors.

## Visual System

### Color Palette (Dark Indie)
```
Background:   #0D0D1A  (deep dark purple-black)
Surface:      #13132B  (dark card/surface)
Elevated:     #1A1A3E  (hover state, elevated elements)
Border:       #2D2D5A  (default borders)

Neon Green:   #00FF88  (primary accent — terminal/indie feel)
Neon Cyan:    #00CFFF  (secondary accent — links/interactive)
Neon Pink:    #FF2DCD  (game dev badge, highlight)
Neon Yellow:  #FFE000  (achievement, CTA)
Neon Red:     #FF3E3E  (danger/alert)

Text Primary:   #E0E0F5
Text Secondary: #8088AA
Text Faint:     #50506A
```

### Typography
- **Display/Headers**: VT323 (large pixel headers — indie game feel)
- **Labels/Buttons/Code**: Space Mono (monospace game UI)
- **Body Copy**: DM Sans (readable for long text)
- **Secondary Display**: Orbitron, Syne

### Key Design Elements
- CRT scanline overlay (`scanlines` CSS class)
- Moving scan beam effect
- Pixel shadow buttons: `4px 4px 0 0 <neon-color>` with hover translate
- HUD corner brackets: `border-t border-l` style corners
- Terminal-style labels with `//`, `>`, `$` prefixes
- Neon text glow via `text-shadow`
- Dark cards with colored left border (skill tree items)
- Game mission numbers on portfolio items

### Photography Treatment
- Ken's portrait: `.crt-portrait` class (CSS contrast + scanline overlay + neon tint)
- White-bg portfolio images: Dark overlay `rgba(13,13,26,0.08)` + dark card background
- Travel/about photos: neon border on hover with `box-shadow: 3px 3px 0 0 <color>`

### White-Background Image Solution
Portfolio images with white backgrounds sit on dark card backgrounds (`#13132B`).
The slight dark overlay + neon border on hover makes them feel intentional.
This creates a "screenshot" / "game card" aesthetic — appropriate for the indie dev brand.

## Sections

### Home (index.jsx)
- Hero: Terminal boot sequence → VT323 name → neon XP bars → CRT portrait
- Marquee band: scrolling stats with alternating neon colors
- Work: "// SHIPPED.LOG" — dark cards with neon border on hover
- Profile: "// CHARACTER.INFO" — stat grid + skill tree
- Writing: "// DEVLOG.MD" — terminal-style article list
- CTA: "INSERT COIN" style

### Header
- Always dark background, neon green accent for active state
- VT323 "▶ KEN.EXE" logo
- Tab-style nav with neon fill for active
- Mobile: full-screen dark overlay with SELECT SCREEN header

### Footer
- Minimal dark footer
- `// Navigate` and `// Connect` section labels
- Gradient accent line at top

## Anti-Patterns (Avoid)
- White backgrounds anywhere (use dark surfaces)
- Light/pastel color schemes
- Sans-serif generic fonts (no Inter, no Roboto)
- Rounded corners (borderRadius = 0)
- Generic purple gradients
- "Regular portfolio" feeling — it should feel like a game developer's page

## Tech Stack
- Next.js 16 (Pages Router)
- React 19
- Tailwind CSS v3 with custom dark tokens
- shadcn/ui (Radix-based)
- VT323 + Space Mono + DM Sans from Google Fonts
